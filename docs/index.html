💬 Offline Chat Archives • 100% Privacy

Relive Conversations with Zero Cloud Intrusion.

A high-performance Android utility built with Jetpack Compose and Material 3 Expressive for managing and visualizing WhatsApp and Instagram chat archives offline. Zero internet permissions, in-app audio playback, and SAF media export.

↓ Download Universal Release APK Browse Release Notes View Source Code
💬
WhatsApp & Instagram Parsers
Full-fidelity parsing of WhatsApp .txt chat exports and official Instagram ZIP/HTML data archives into offline Room SQLite storage.
🎵
Embedded Audio Player
In-app audio playback manager for voice notes, memos, and sound clips directly within the conversation thread timeline.
🖼️
Zero-Permission Media Export
Safely export photos, videos, and documents to device gallery via Storage Access Framework (SAF) without requesting blanket storage permissions.
🎨
Material 3 Expressive Glassmorphism
Pristine blank canvas home screen, dynamic time-of-day greetings, and multi-layer frosted glass card with organic animated message count.
👤
Modern Android Photo Picker
Personalize your profile identity using the system Android Photo Picker flow with zero runtime permission popups.
🛡️
Zero Network Access
Absolutely no INTERNET permission declared in AndroidManifest.xml. Zero telemetry, zero analytics, and 100% device isolation.
Architectural Specifications
PlatformNative Android (100% Kotlin & Jetpack Compose)
Target / Min SDKAndroid 14 (API 34) / Android 8.0 (API 26)
Design LanguageMaterial 3 Expressive (Layered glassmorphism, dynamic color)
Local DatabaseRoom (SQLite) with KSP
